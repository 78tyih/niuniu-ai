# P15 · 下单建议输出格式（前端渲染契约）

## 用途

**边界修正新增**。定义下单建议卡片的结构化 JSON 契约：AI 返回该 JSON，前端收到 `type=order_suggestion` 就渲染成卡片 + 一键下单按钮，不落成纯文本。被 P30（下单建议生成）引用。

## 触发场景

AI 产出任何交易建议时，输出必须符合本契约；不符合契约的输出视为无效，前端不渲染按钮。

## 模板正文

> 交易建议必须输出为如下 JSON（字段缺一不可，缺止损则整张卡片不生成）：
>
> ```json
> {
>   "type": "order_suggestion",
>   "symbol": "EURUSD",
>   "side": "BUY",
>   "entry_ref": "市价",
>   "sl_points": 400,
>   "tp_points": 800,
>   "risk_pct": 0.5,
>   "reason": "一句话理由",
>   "confidence": "mid",
>   "data_note": "",
>   "risk_warning": "按 0.5% 风险、0.01 手计算，本笔最多亏约 X 元"
> }
> ```
>
> 字段规则：
>
> - `type`：固定 `order_suggestion`。
> - `side`：`BUY` 或 `SELL`。
> - `entry_ref`：入场参考（如「市价」），当前执行链只支持市价开仓。
> - `sl_points`：止损点数，**必填且 > 0**；≤ 0 时禁止生成卡片。
> - `tp_points`：止盈点数，可为 0。
> - `risk_pct`：建议单笔风险占余额百分比，默认 0.5；手数由系统按「风险% × 余额 ÷ 止损距离」计算，**AI 不输出手数数字**。
> - `confidence`：`high | mid | low`；数据不足时必须为 `low` 并在 `data_note` 说明。
> - `risk_warning`：风险提示，手数与金额部分由系统计算后填入，AI 只给句式。

## 红线

- 无止损（sl_points ≤ 0）不生成卡片、前端不提供「一键下单」按钮。
- JSON 中不得出现手数（lots）字段；下单量永远由确定性程序产生。
- 卡片不等于成交：必须经过「一键下单按钮 → 二次确认」人工确认链。
- 数据不足时禁止硬给点位凑满字段。
