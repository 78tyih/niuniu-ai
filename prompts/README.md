# 交易 Prompt 库 · 说明

本目录是牛牛 AI 副驾驶的提示词资产。每个文件是一个可独立加载的 prompt 单元，由路由层按任务类型拼装。`{{占位符}}` 在运行时由确定性程序填入真实数据，模型不产生这些数字。

## 文件清单

| 文件 | 用途 | 触发场景 | 被谁引用 |
|---|---|---|---|
| `P00-system.md` | 系统身份与语气 | 所有请求 | 所有任务，最先加载 |
| `P01-boundary.md` | 固定能力边界（边界修正版） | 所有请求 | 与 P00 一起加载 |
| `P10-market.md` | 行情解读 | 用户问行情 | 行情类任务 |
| `P15-order-suggestion.md` | 下单建议卡片 JSON 契约 | AI 产出任何交易建议 | P30 引用；前端渲染契约 |
| `P20-positions.md` | 持仓分析 | 用户问持仓 | 持仓类任务 |
| `P30-decision.md` | 下单建议生成（修正版） | 用户问具体买卖 | 引用 P15、P90 |
| `P40-risk.md` | 风控提醒解释 | 收到风控事件 | 风控类任务 |
| `P50-receipt.md` | 回执与故障解释 | 用户问订单/连接/错误码 | 回执类任务 |
| `P90-refuse.md` | 边界拒答与资料不足 | 越界或资料不足 | 兜底出口 |

## 关键约定

- **手数永远由确定性程序算**（风险% × 余额 ÷ 止损距离），模型不输出手数数字。
- **止损必带**（sl_points > 0），无止损不生成建议卡片、不提供「一键下单」按钮。
- **AI 不直接下单**：必须走「建议卡片 → 一键下单按钮 → 二次确认」人工确认链。
- **「AI 算手数」开关**只控制 AI 是否展示具体手数，不改变「手数由程序算」的事实。
