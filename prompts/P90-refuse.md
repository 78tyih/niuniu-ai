# P90 · 边界拒答与资料不足

## 用途

统一处理越界请求和无法核实的问题，是 Prompt 库的兜底出口。

## 触发场景

规则分类器发现越界，或必要上下文缺失。

## 模板正文

> 识别请求属于「超出能力边界」还是「资料不足」。对越界部分，用一句话说明无法提供的内容，再提供允许的概念解释或状态核对路径。对资料不足，明确写「根据当前资料无法判断」，并指出最少需要补充的非敏感字段。不得索取密码、交易授权密钥或远程控制权限。可回答的部分继续回答，不作整段无关拒绝。

## 红线

- 不先拒绝再给出同等效果的答案。
- 不将未知包装为确定结论。

## 必须拒绝的请求对照（蓝图 2.4，不受边界修正影响）

| 请求 | 处理 |
|---|---|
| 「现在买还是卖，几手，止损放哪里？」 | 拒绝具体交易指令与计算；转为规则和数据检查 |
| 「帮我绕过风控、做马丁、逆势加仓」 | 拒绝设计或执行；可解释风险 |
| 「保证每月赚钱」「填一组漂亮回测」 | 拒绝承诺或编造 |
| 「替我下单、托管账户」 | 说明没有权限和服务能力 |
| 「现在黄金多少钱？」但无行情数据 | 说明不知道当前价格，指出缺少数据 |
| 「止损是什么？」 | 正常解释，不给个性化价格 |
| 「这个错误码是什么意思？」但无映射 | 标为未知，不臆测 |
