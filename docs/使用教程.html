030 秒看懂：它到底是什么

软件自己不下单。它把你的指令签名后写成一个文件，交给 MT5 里的桥接 EA，EA 校验通过才替你下单。

记住一句话：软件负责「说清楚要做什么」，EA 负责「决定能不能做」。两边各自校验，谁都不能单独放行。

2第 1 步 · 准备

MT5 已装好，并登录一个模拟账户。牛牛 AI 不替代 MT5，它是挂在 MT5 上的一层 —— MT5 不动，它也不动。

  • 没装 MT5？去你的券商官网下载安装。这一步必须要联网。
  • 没有模拟账户？MT5 里点「文件 → 开设账户 → 找一个服务器 → 下一步」，填点基本资料就有一个免费的。
  • 确认工具栏上有「自动交易 / Algo Trading」按钮。先别管它是开还是关。
  • 测试阶段请只用模拟账户。EA 默认参数 InpDemoOnly = true，用实盘账户会被拒绝。

3第 2 步 · 安装软件

双击安装包，一路下一步。

  1. 双击 NiuNiuAI-Setup-1.0.0.exe
  2. 弹出「已保护你的电脑」→ 点更多信息 → 仍要运行
    测试版没买代码签名证书，正常现象
  3. 一路下一步，不需要管理员权限，自动建桌面快捷方式
  4. 双击桌面「牛牛AI」启动

4第 3 步 · 激活授权

复制整串密钥，粘贴到顶部授权框，点「激活」。

  • 复制整串密钥（含开头的 NN1-，中间有一个点，别截段）
  • 粘贴到顶部授权框，点「激活」（或直接回车）
  • 变绿 = 成功。密钥是 Ed25519 离线验签，不需要联网，也不上传任何数据
  • 没激活也能看行情，但一下单就会被拦：「未授权 · 请先激活」

5第 4 步 · 安装桥接 EA

在软件里点一下就行。

这一步实际做了两件事

  • 把 NiuNiuBridge.ex5 拷进 MT5 的 Experts 目录
  • 把一把本机随机生成的密钥写进 MT5 沙箱
密钥决定了「你这台电脑有资格给 EA 下命令」。所以顺序不能反：先点安装，再去挂 EA。
看到日志里出现 EA 已安装：…\MQL5\Experts\NiuNiuBridge.ex5 就成功了。

4.5 步 · 把 EA 挂到图表上（软件不会替你挂）

最常踩的两个坑：① InpAutoTrade 忘了改成 true —— 能连上、能看到行情，但一下单就被拒；② EA 是在点「安装桥接 EA」之前挂上的 —— 密钥没读到，把 EA 移除再重拖一次。

6第 5 步 · 确认状态

三盏灯全绿才继续。

你看到的含义怎么办
余额 / 净值已连上继续
买价 / 卖价行情通了继续
签名校验已启用安全链路通继续
未启用签名EA 没拿到密钥回第 4 步重装 + 重启 EA
一直未连接EA 没在跑回 4.5 步看笑脸
左侧「持仓 Positions」会列出 MT5 里当前所有持仓 —— 这是判断真成没成交的唯一依据。

7第 6 步 · 下一单

先填，再看小票，最后才点确认。

字段说明测试值
方向 Side买入 BUY / 卖出 SELLBUY
手数 Lots手数0.01
止损 sl_points填 0 = 不设0 或 250
止盈 tp_points填 0 = 不设0 或 500
滑点 deviation允许的价格偏离30
「点」不是 pip。point = 品种最小报价单位，黄金 1 point ≈ 0.01 美元。手数与止损 EA 还会按券商规格再校验一遍。

8第 7 步 · 看懂回执

只有「已成交」才算成。

9平仓

在持仓表格里点最右边那个按钮。

  • 平仓同样走一遍回执流程，别看到没立刻消失就以为失败了
  • 成功后持仓从表格消失，MT5 里也同步消失
  • 如果回执是「待核对」——以 MT5 里的真实持仓为准
急停：点顶部「运行中 · 点击停用」→ 变「⛔ 已停用」。已发出的命令仍会走完，这是对的 —— 急停只拦新的。

11风险提示（请务必读）

  1. 本软件是执行工具，不是投资建议。它把你点的按钮原样送给券商，不判断该不该做这笔交易。
  2. 自动交易存在技术风险：断线、延迟、滑点、券商拒单、MT5 崩溃，都可能让结果和预期不一致。回执不是「已成交」的时候，一律以 MT5 终端里的真实持仓为准。
  3. 看到「待核对」必须人工核对，不要重复提交。
  4. 测试阶段请只用模拟账户，不要用真实资金。
  5. 开发者不对任何交易盈亏、间接损失承担赔偿责任。
