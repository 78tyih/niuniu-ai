# 牛牛 AI · 安装与使用操作步骤（Windows）

> 适用版本：v1.0.0 · 仅支持 Windows 64 位 · **测试阶段请只用模拟账户**
>
> 阅读顺序：第 0 节看边界 → 第 1~4 节装好 → 第 5 节确认状态 → 第 6~8 节用起来 → 出问题查第 10 节。

---

## 0. 先搞清楚这东西是什么

牛牛 AI 是一个**装在你本机的交易辅助软件**。它自己不下单，而是通过一个
**桥接 EA** 接到你的 MetaTrader 5（MT5）上：你在牛牛 AI 里点下单，
它把命令写成一个带签名的文件交给 MT5 里的 EA，EA 校验通过后才替你下单。

**v1 能做的：**

- 自动找到你电脑上的 MT5
- 一键市价买卖（手数 / 止损 / 止盈）
- 一键平仓
- 实时看余额、净值、可用保证金、报价、持仓
- 全局急停、导出日志

**v1 还没做的（别找，找不到）：**

- ❌ AI 聊天 / AI 分析 —— 界面上那块是占位说明，**v1 不接模型**
- ❌ 自动更新
- ❌ macOS 版本

**两个刻意的默认限制（这俩最容易被误当成"坏了"）：**

| 限制 | 表现 | 怎么改 |
|---|---|---|
| **只允许模拟账户** | 用实盘账户下单会被拒，回执写「仅允许模拟盘」 | EA 参数 `InpDemoOnly` 改成 `false` |
| **默认不允许下单** | 能连上、能看到行情，但一下单就被拒，回执写「EA 自动交易开关关闭」 | EA 参数 `InpAutoTrade` 改成 `true`（**装完必做，见第 4 节第 6 步**） |

## 1. 准备工作

### 1.1 装 MetaTrader 5

如果还没装：到你的券商官网下载 MT5 安装包，装好并**登录一个模拟账户**。

> 没有模拟账户？在 MT5 里点「文件 → 开设账户 → 找一个服务器 → 下一步」，
> 填点基本资料就能开一个免费的。**这一步必须要联网。**

### 1.2 确认 MT5 能正常交易

登录后确认工具栏上的「**自动交易 / Algo Trading**」按钮存在，先别管它是开还是关。

---

## 2. 安装牛牛 AI

1. 双击 `NiuNiuAI-Setup-1.0.0.exe`。
2. Windows 可能弹「**已保护你的电脑 / SmartScreen**」——因为测试版没买代码签名证书。
   点「**更多信息**」→「**仍要运行**」。
3. 一路下一步，它会自动装到当前用户目录并创建桌面快捷方式，**不需要管理员权限**。
4. 双击桌面的「**牛牛AI**」图标启动。

启动后你应该看到：顶部是标题和「运行中 · 点击停用」，下面是 ① 选择终端 / ② 安装桥接 EA / ③ 绑定与下单 三个步骤条。

---

## 3. 安装桥接 EA（在牛牛 AI 里点一下就行）

1. 打开 MT5，**保持它运行**。
2. 回到牛牛 AI：
   - 「MT5 终端」卡片会自动扫描，列出找到的终端（通常只有一条）。
   - **点它选中**（会高亮，右边显示进程 ID 和路径）。
   - 点「**安装桥接 EA**」。
3. 看到日志里出现 `EA 已安装：...\MQL5\Experts\NiuNiuBridge.ex5` 就成功了。

> 这一步做两件事：把 EA 文件拷进 MT5；把一把**本机随机生成的密钥**写进 MT5 沙箱。
> 密钥决定了你的电脑有资格给 EA 下命令——所以**顺序不能反**：先点安装，再去挂 EA。

---

## 4. 把 EA 挂到图表上（**最关键的一步**）

牛牛 AI 只是把 EA 文件放进去了，**它不会替你挂**。必须手动挂一次：

1. 打开 MT5，按 `Ctrl+N` 打开「导航器」。
2. 展开「**EA 交易**」，找到 **NiuNiuBridge**。
3. **把它拖到任意一个图表上**（比如 EURUSD 的图）。松手后会弹出「EA 属性」窗口。
4. 在属性窗口的「**常用**」标签页，勾上「**允许算法交易**」。
5. 切到「**输入参数**」标签页，把这两项改掉：
   - `InpAutoTrade` → 改成 **`true`** ← **不改这个，下单一定失败**
   - `InpDemoOnly` → 保持 `true`（测试阶段）
6. 点「确定」。
7. 确认三件事：
   - 工具栏上「**自动交易 / Algo Trading**」按钮是**绿色**（没绿就点一下）；
   - 图表右上角出现**笑脸** 😊（如果是 ✕ 或 😴 就说明没挂好或没允许算法交易）；
   - MT5 底部「工具箱 → EA 交易」标签里能看到 `[NN] ═══ 牛牛 AI 桥接 EA 已启动 ═══`。

> **如果 EA 是在你点「安装桥接 EA」之前就挂上的**：请把 EA 从图表上移除再重新拖一次，
> 或者在图表上右键 →「EA 交易」→「属性」→ 确定，让它重新初始化一次。
> 原因：密钥只在 EA 启动那一刻读取。

---

## 5. 回到牛牛 AI 确认状态

看右边「账户与行情」卡片：

| 你看到的 | 含义 | 该怎么办 |
|---|---|---|
| 余额 / 净值 / 可用保证金 有数字 | ✅ 已连上 | 继续 |
| 品种、买价、卖价 有数字 | ✅ 行情通了 | 继续 |
| 一行小字：`签名校验已启用`（绿色） | ✅ 安全链路通了 | 继续 |
| 红色：`未启用签名 · 交易命令将被拒绝` | ❌ EA 没拿到密钥 | 回第 3 节重新点一次安装，再回第 4 节重启 EA |
| 一直是「未连接 / EA 未运行」 | ❌ EA 没在跑 | 回第 4 节检查笑脸和自动交易按钮 |

左侧「持仓 Positions」会列出 MT5 里当前所有持仓。

---

## 6. 下单

在右边「**人工下单 · 交易票据**」卡片里填：

| 字段 | 说明 | 建议测试值 |
|---|---|---|
| 方向 Side | 买入 BUY / 卖出 SELL | 买入 BUY |
| 手数 Lots | 手数 | **0.01**（最小手，测试用） |
| 止损（点） | `sl_points`，填 0 = 不设 | 0 或 250 |
| 止盈（点） | `tp_points`，填 0 = 不设 | 0 或 500 |
| 允许滑点（点） | 允许的价格偏离 | 30 |

填完先看下面的「**下单前确认**」小票：账户、服务器、品种、方向手数、止损止盈都对不对。
不对就别点。确认无误后点「**确认下单（模拟盘）**」。

> **「点」是什么单位？** point = 这个品种的最小报价单位，**不是 pip**。
> 比如黄金 1 point ≈ 0.01 美元。手数和止损距离 EA 还会按券商规格再校验一遍。

然后看底部「**事件与回执**」：

```
命令 … 已发出
回执 … → [已受理] 已受理，提交中
回执 … → [已成交] 已成交        ← 成功
```

如果失败，回执会写明确原因，例如「手数越界」「止损距离小于 STOPS_LEVEL」「EA 自动交易开关关闭」。
失败原因直接读文字就行，不用猜。

---

## 7. 看懂回执状态（这段建议读一遍）

| 状态 | 什么意思 | 你要做什么 |
|---|---|---|
| `已发出` | 命令发出去了，EA 还没回话 | 等 |
| `已受理` | EA 校验通过，正在提交券商 | 等 |
| `已成交` | 券商确认成交 | 无 |
| `已拒绝` | 明确失败 | 读后面的原因 |
| `已过期` | 命令超过有效期才开始处理 | 可以重发，不会重复成交 |
| **`待核对`** | **结果不明**：请求可能已经发出去了，但不知道到底成没成 | **去 MT5 看真实持仓，不要重复下单** |

> ⚠️ **`待核对` 是刻意设计的，不是 bug。**
> 系统永远不替你自动重发一条结果不明的交易命令——那才是真的会重复成交。
> 宁可让你看到「待核对」，也不给你一个假的「已成交」。

---

## 8. 平仓

在左边「持仓 Positions」表格里，找到要平的那一行，点最右边的「**平仓**」。

- 会弹确认框，确认即可。
- 平仓同样会走一遍下面的回执流程。
- 成功后持仓从表格里消失，MT5 里也消失。

---

## 9. 停用与退出

| 想做什么 | 怎么做 |
|---|---|
| **紧急停止**（不再接受新交易指令） | 点顶部的「**运行中 · 点击停用**」→ 变成「⛔ 已停用」。**已发出的命令仍然会走完**，这是对的 |
| 恢复 | 再点一次 |
| 彻底停止交易 | 在 MT5 里点「自动交易」按钮变红，或把 EA 从图表上移除 |
| 导出日志给客服 | 用日志功能把「事件与回执」里的内容存成 txt |
| 卸载软件 | 设置 → 应用 → 牛牛AI → 卸载 |
| **完全清理** | 卸载软件后，还要在 MT5 里删除 `NiuNiuBridge`（图表右键移除 + 导航器里删文件），并删掉 `MQL5\Files\niuniu\` 文件夹 |

## 10. 出问题了怎么办

| 现象 | 原因 | 解决 |
|---|---|---|
| 终端列表里显示「EA 未运行」 | EA 没挂到图表，或自动交易没开 | 回第 4 节，检查笑脸和绿色按钮 |
| 下单立刻被拒：「EA 自动交易开关关闭」 | EA 参数 `InpAutoTrade` 还是 `false` | 第 4 节第 5 步，改成 `true` |
| 下单被拒：「仅允许模拟盘」 | 你登录的是实盘账户 | 换模拟账户，或把 `InpDemoOnly` 改 `false`（测试阶段不建议） |
| 红色「未启用签名 · 交易命令将被拒绝」 | EA 没拿到密钥 | 第 3 节点一次「安装桥接 EA」→ 第 4 节重启 EA |
| 命令一直停在「已发出」 | EA 没在跑，或选错了终端 | 多终端会各自独立，确认选的是挂了 EA 的那个 |
| 全部被拒，回执写「账户不匹配」 | 命令里的账号不是当前登录的账号 | 换账户后要点「重新绑定（换账户）」 |
| 换账户后旧命令失效 | 正常现象：代次 epoch 变了 | 无用，重新下单即可 |
| 下单被拒：「止损距离小于 STOPS_LEVEL」 | 止损设得太近 | 把止损点数调大 |
| 图表右上角是 ✕ 不是笑脸 | 没允许算法交易 | 属性里勾「允许算法交易」 |
| 软件打不开 / 白屏 | 被杀软拦了 | 加白名单后重开 |

**手动兜底：文件都装在哪**

```
EA 本体      %APPDATA%\MetaQuotes\Terminal\<实例ID>\MQL5\Experts\NiuNiuBridge.ex5
桥工作目录   %APPDATA%\MetaQuotes\Terminal\<实例ID>\MQL5\Files\niuniu\
             ├─ inbox\       待执行命令
             ├─ outbox\      回执
             ├─ archive\     已执行命令（防重复用）
             ├─ quarantine\  被拒的命令（留着查原因）
             └─ secret.json  密钥（删了就回第 3 节重装）
```

## 11. 风险提示（请务必读）

1. **本软件是执行工具，不是投资建议。** 它把你点的按钮原样送给券商，不判断该不该做这笔交易。
2. **自动交易存在技术风险**：断线、延迟、滑点、券商拒单、MT5 崩溃，都可能让结果和预期不一致。
   **回执不是「已成交」的时候，一律以 MT5 终端里的真实持仓为准。**
3. **看到「待核对」必须人工核对**，不要重复提交。
4. **测试阶段请只用模拟账户**，不要用真实资金。
5. 开发者不对任何交易盈亏、间接损失承担赔偿责任。
