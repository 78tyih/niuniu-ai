牛牛 AI · 安装与使用操作步骤

适用于 Windows 64 位 · 测试阶段请只用模拟账户 · 全程约 10 分钟

0先搞清楚这东西是什么

牛牛 AI 是一个装在你本机的交易辅助软件。它自己不下单，而是通过一个桥接 EA 接到你的 MetaTrader 5 上：你在牛牛 AI 里点下单，它把命令写成一个带签名的文件交给 MT5 里的 EA，EA 校验通过后才替你下单。

v1 能做的v1 还没做的
自动找到本机 MT5
一键市价买卖（手数/止损/止盈）
一键平仓
实时看余额·净值·保证金·报价·持仓
全局急停、导出日志		 未开放 AI 聊天 / AI 分析
未接线 自动更新
不做 macOS 版本
⚠️
两个刻意的默认限制，最容易被误当成「坏了」：
只允许模拟账户实盘下单被拒，回执写「仅允许模拟盘」EA 参数 InpDemoOnly 改 false
默认不允许下单能连上、能看行情，但一下单就被拒，回执写「EA 自动交易开关关闭」EA 参数 InpAutoTrade 改 true
装完必做，见第 4 节

1准备工作

1.1 装 MetaTrader 5

到券商官网下载 MT5 安装包，装好并登录一个模拟账户。

💡
没有模拟账户？在 MT5 里点「文件 → 开设账户 → 选一个服务器 → 下一步」，填点基本资料就能开免费的。这一步必须联网。

1.2 确认 MT5 能正常交易

登录后确认工具栏上有「自动交易 / Algo Trading」按钮。先别管它是开是关。

2安装牛牛 AI

  1. 双击 NiuNiuAI-Setup-1.0.0.exe。
  2. Windows 可能弹「已保护你的电脑 / SmartScreen」——测试版没买代码签名证书，属正常。点「更多信息」→「仍要运行」。
  3. 一路下一步。装到当前用户目录，不需要管理员权限。
  4. 双击桌面的「牛牛AI」启动。

启动后应看到：顶部标题和「运行中 · 点击停用」，下面是 ① 选择终端 / ② 安装桥接 EA / ③ 绑定与下单 三个步骤条。

3安装桥接 EA

  1. 打开 MT5，保持它运行。
  2. 回到牛牛 AI：「MT5 终端」卡片会自动扫描并列出终端（通常只有一条）。
  3. 点它选中（高亮，右侧显示进程 ID 和路径）。
  4. 点「安装桥接 EA」。
  5. 看到日志出现 EA 已安装：…\MQL5\Experts\NiuNiuBridge.ex5 即成功。
🔑
这一步做两件事：把 EA 拷进 MT5；把一把本机随机生成的密钥写进 MT5 沙箱。密钥决定你的电脑有资格给 EA 下命令——所以顺序不能反：先点安装，再去挂 EA。

4把 EA 挂到图表上 最关键

牛牛 AI 只是把 EA 文件放进去了，它不会替你挂。必须手动挂一次：

  1. 在 MT5 按 Ctrl+N 打开「导航器」。
  2. 展开「EA 交易」，找到 NiuNiuBridge。
  3. 拖到任意一个图表上（比如 EURUSD 的图），松手会弹出「EA 属性」窗口。
  4. 「常用」标签页 → 勾上「允许算法交易」。
  5. 切到「输入参数」标签页，改这两项：
    • InpAutoTrade → 改成 true　← 不改这个，下单一定失败
    • InpDemoOnly → 保持 true（测试阶段）
  6. 点「确定」。
  7. 确认三件事：
    • 工具栏「自动交易」按钮是绿色（没绿就点一下）；
    • 图表右上角是笑脸 😊（✕ 或 😴 说明没挂好）；
    • MT5 底部「工具箱 → EA 交易」标签能看到 [NN] ═══ 牛牛 AI 桥接 EA 已启动 ═══。
⚠️
如果 EA 是在点「安装桥接 EA」之前就挂上的：请把它移除后重新拖一次，或在图表上右键 →「EA 交易」→「属性」→ 确定，让它重新初始化。原因：密钥只在 EA 启动那一刻读取。

5回到牛牛 AI 确认状态

看右边「账户与行情」卡片：

你看到的含义该怎么办
余额/净值/保证金 有数字已连上继续
品种、买价、卖价 有数字行情通了继续
小字「签名校验已启用」（绿）安全链路通了继续
红字「未启用签名 · 交易命令将被拒绝」缺密钥回第 3 节重点一次安装，再回第 4 节重启 EA
一直「未连接 / EA 未运行」EA 没在跑回第 4 节检查笑脸和自动交易按钮

左侧「持仓 Positions」会列出 MT5 里当前所有持仓。

6下单

在右边「人工下单 · 交易票据」卡片里填：

字段说明建议测试值
方向 Side买入 BUY / 卖出 SELL买入 BUY
手数 Lots下单手数0.01（最小手，测试用）
止损（点）sl_points，0 = 不设0 或 250
止盈（点）tp_points，0 = 不设0 或 500
允许滑点（点）允许的价格偏离30

填完先看下面的「下单前确认」小票：账户、服务器、品种、方向手数、止损止盈都对不对。不对就别点。确认无误后点「确认下单（模拟盘）」。

📏
「点」是什么单位？ point = 该品种的最小报价单位，不是 pip。比如黄金 1 point ≈ 0.01 美元。手数和止损距离 EA 还会按券商规格再校验一遍。

然后看底部「事件与回执」：

命令 … 已发出 回执 … → [已受理] 已受理，提交中 回执 … → [已成交] 已成交 ← 成功

失败时回执会写明确原因，例如「手数越界」「止损距离小于 STOPS_LEVEL」「EA 自动交易开关关闭」。直接读文字就行，不用猜。

7看懂回执状态

状态什么意思你要做什么
已发出命令发出去了，EA 还没回话等
已受理EA 校验通过，正在提交券商等
已成交券商确认成交无
已拒绝明确失败读后面的原因
已过期命令超过有效期才开始处理可重发，不会重复成交
待核对结果不明：请求可能已发出，但不知道成没成去 MT5 看真实持仓，不要重复下单
🛡️
「待核对」是刻意设计的，不是 bug。系统永远不替你自动重发一条结果不明的交易命令——那才是真的会重复成交。宁可让你看到「待核对」，也不给你一个假的「已成交」。

8平仓

在左边「持仓 Positions」表格里找到要平的那一行，点最右边的「平仓」。

  • 会弹确认框，确认即可。
  • 平仓同样走一遍下面的回执流程。
  • 成功后持仓从表格里消失，MT5 里也消失。

9停用与退出

想做什么怎么做
紧急停止点顶部「运行中 · 点击停用」→ 变成「⛔ 已停用」。已发出的命令仍会走完，这是对的
恢复再点一次
彻底停止交易MT5 里点「自动交易」变红，或把 EA 从图表移除
导出日志给客服用「事件与回执」区的导出功能存成 txt
卸载软件设置 → 应用 → 牛牛AI → 卸载
完全清理卸载后还要在 MT5 里移除 NiuNiuBridge，并删掉 MQL5\Files\niuniu\ 文件夹

11风险提示

  1. 本软件是执行工具，不是投资建议。它把你点的按钮原样送给券商，不判断该不该做这笔交易。
  2. 自动交易存在技术风险：断线、延迟、滑点、券商拒单、MT5 崩溃，都可能让结果和预期不一致。回执不是「已成交」的时候，一律以 MT5 终端里的真实持仓为准。
  3. 看到「待核对」必须人工核对，不要重复提交。
  4. 测试阶段请只用模拟账户，不要用真实资金。
  5. 开发者不对任何交易盈亏、间接损失承担赔偿责任。

12给测试人员的反馈清单

测完请按下面几条反馈实际结果，越具体越有用：

  • ☐ 系统版本（Win10 / Win11，多少位）
  • ☐ 券商名称 + 账户类型（模拟 / 实盘）
  • ☐ 第 3 节「安装桥接 EA」是否成功？日志原文
  • ☐ 第 4 节挂 EA 后，图表右上角是笑脸吗？
  • ☐ 第 5 节「签名校验已启用」是绿色吗？
  • ☐ 下单结果：回执显示「已成交」了吗？把整行回执文字复制回来
  • ☐ 平仓结果：同上
  • ☐ 有没有出现「待核对」？出现过就说明这个要重点查
  • ☐ 截图：① 主界面全貌 ② 下单后的回执区 ③ MT5 的「EA 交易」日志标签
  • ☐ 你觉得哪里别扭 / 看不懂 / 多余
📋
