## 一、项目背景（牛牛AI）

牛牛AI（niuniuai.app），面向 **Windows + MT5** 的交易助手。目标形态：策略广场 + DIY 看板 + AI 副驾驶 + MT5 EA 桥接执行。
桌面客户端（Electron）已落地并验证：
- 授权离线校验（公钥在客户端，客户伪造不出密钥）；**未授权不能下单**，但可看行情、可装 EA。
- 桥接 EA 跑在客户自己的 MT5；随机密钥 + epoch 代次（换账户即作废旧命令）。
- 命令回执有 stage：SENT / EXECUTED / REJECTED / **RECONCILING（结果未知，禁止自动重放，要求人工核对）** / EXPIRED。
- AI 网关：客户端只持用户令牌，模型 Key 在服务端；按用量扣积分；未配置则整条状态栏不显示。
- 安全边界：主进程参数二次校验 + 命令类型白名单 + `terminalPath` 必须含 MetaQuotes + 手数范围校验；渲染层 contextIsolation + sandbox，CSP 禁止 inline 脚本。
- 商业化现状：官网已有订阅计划与分销/推荐体系，支付 ZPay + Stripe，后端 Supabase。

**核心差别（必须牢记）**：**客户资金从来不在我们这里** —— EA 跑在客户自己的 MT5 账户里。这与加密货币平台的托管/非托管语境都不同。

- 详情页 7 段：作者信息 / 策略说明 / 绩效摘要（总收益、年化、胜率、最大单笔盈利、夏普、最大回撤）/ **绩效图（回测段 + 发布标记 + live-forward 段，官方明确要求不得读成一条连续实盘曲线）** / 详细绩效（收益、期望收益、手续费、多空分列、收益、Sharpe、Sortino、Calmar）/ 交易分析（笔数、多空占比、胜率、平均盈亏、profit factor、连胜连败）/ 我的实盘运行。

### AlphaFox（alphafox.app 灵狐量化）
- 三种形态明确区分：**复制**（复制策略参数，由自己账户独立运行，**复制的是参数不是收益**）、**跟单**（跟随带单员之后的新开平仓，**不补开已有持仓**）、**托管模板**（网格 / DCA / 趋势 / 马丁）。
- 榜单规则：**只列出所选周期收益率高于 -30% 的策略**；官方建议切 90 天以上先看回撤；「公开」的可复制，「未公开」的只展示指标。
- 上手路径：注册领 3 天 Pro → 逛排行榜 → 添加**模拟交易所**（不要真实 API Key）→ 四步创建策略（**创建前提示免费还是按小时计费**）→ 看收益曲线/持仓/订单/事件，跑顺再实盘。
- 安全红线：API 非托管 + **不给提现权限（检测到就亮红）** + 历史收益不是承诺 + 先模拟再实盘。
- 关键约束：**一个交易账户同一时间只能被一个运行中的策略使用**（避免抢仓位和保证金）。

### Mojo（mojo.trade）
- 六大能力共享同一段对话：Research / Charts / **Boards（描述式自建看板）** / Watch / Trade / Review。
- **审批与控制**：策略生成后是「策略卡」，展示场所、条件、仓位、风控；**未经用户批准什么都不运行**；可随时查看 Agent 状态与记录；**停止 Agent 不会自动平掉已开仓位**。
- 创始人访谈要点：①「谁定什么」——用户定「下多少、什么条件止盈止损」，Agent 负责把话写成策略，**可用余额、下单量换算、止损价落地由确定性程序算，模型不参与**；②**五层资金账本，任一层数据缺失就不下单，绝不用 0 填补**；③接入就意味着持有执行授权，**所以不宣称「碰不到你的钱」**，但资产留在用户自己那里；④用户体验取舍——给的是「自己拿主意的感觉」和「拿完主意后立刻看到的反馈」，全自动机器人把「拿主意」也拿走了，用户就流失了。
- 内测用户反馈：正面是「一站式、人性化、会帮我处理跨链、内置重点快讯」；**负面是「它有时候太爱讲话、回答速度有点慢」**。
