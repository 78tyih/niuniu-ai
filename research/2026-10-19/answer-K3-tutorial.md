# 牛牛 AI 客户端使用教程（新手版）

> 适用版本：v1.0 · 仅支持 Windows 64 位 · **测试阶段请只用模拟账户**
>
> 目标：照着做，30 分钟内在模拟盘上跑通「安装 → 连接 → 下单 → 平仓」全流程。
> 阅读顺序：第 1 章搞懂这是什么 → 第 2 章装好（四步闭环）→ 第 3~7 章按页面用 → 出问题查第 8 章。

---

## 1. 这是什么

**一句话定位：牛牛 AI 是装在你自己电脑上的 MT5 交易副驾驶。**

它自己**不下单**。你在牛牛 AI 里点「下单」，它把命令写成一个带签名的文件，交给 MT5 里的「桥接 EA」；EA 校验通过后才真的向券商下单。MT5 不在跑，牛牛 AI 什么都做不了。

### v1 能做什么 / 不能做什么

| v1 能做 | v1 不能做（别找，找不到） |
|---|---|
| 自动扫描你电脑上的 MT5 终端 | ❌ AI 模型聊天 / 实时分析（「AI 副驾驶」当前为**链路演示模式**，模型尚未接入） |
| 一键安装桥接 EA、绑定密钥 | ❌ 策略广场在线订阅（资产库已上线但全部**待回测**，策略仍手动挂 EA 跑，见第 5 章） |
| 人工下单（方向 / 手数 / 止损 / 止盈 / 滑点） | ❌ 自动更新 |
| 一键平仓、回执跟踪 | ❌ macOS 版本 |
| 实时看余额 / 净值 / 可用保证金 / 报价 / 持仓 | |
| 全局一键停用（急停） | |

### 两个刻意的默认限制（最容易被误当成「坏了」）

| 限制 | 表现 | 怎么改 |
|---|---|---|
| **默认不允许下单** | 能连上、能看到行情，一下单就被拒，回执写「EA 自动交易开关关闭」 | EA 参数 `InpAutoTrade` 改成 `true`（装完必做，见 2.4 第 5 步） |
| **测试阶段只允许模拟账户** | 用实盘账户下单会被拒，回执写「仅允许模拟盘」 | 换模拟账户（EA 参数 `InpDemoOnly` 保持 `true`） |

## 2. 安装：四步闭环

总览：**① 装 MT5 → ② 装牛牛 AI → ③ 在牛牛 AI 里装桥接 EA → ④ 把 EA 手动挂到图表**。
四步缺一不可，顺序不能乱（原因见 2.3 的说明）。

### 2.1 第一步：装 MetaTrader 5

1. 到你的券商官网下载 MT5 安装包，安装。
2. 打开 MT5，**登录一个模拟账户**。
   - 没有模拟账户？MT5 菜单「文件 → 开设账户 → 找一个服务器 → 下一步」，填基本资料免费开一个。**这一步要联网。**
3. 确认工具栏上有「**自动交易 / Algo Trading**」按钮（先不用管它是开是关）。

### 2.2 第二步：装牛牛 AI

1. 双击 `NiuNiuAI-Setup-1.0.0.exe`。
2. Windows 可能弹「**已保护你的电脑 / SmartScreen**」——测试版没买代码签名证书。点「**更多信息**」→「**仍要运行**」。
3. 一路下一步，装到当前用户目录，**不需要管理员权限**。
4. 双击桌面「**牛牛AI**」图标启动。

启动后先看**顶部授权条**：粘贴你的授权密钥（`NN1-…` 开头），点「**激活**」。未授权时不能交易。

### 2.3 第三步：安装桥接 EA（在牛牛 AI 里点一下）

1. 打开 MT5，**保持它运行**。
2. 打开牛牛 AI 左侧「**终端与 EA**」页：
   - 「MT5 终端」卡片会自动扫描，列出找到的终端。
   - **点选你的终端**（高亮，显示进程 ID 和路径）。
   - 点「**安装桥接 EA**」。
3. 日志出现 `EA 已安装：...\MQL5\Experts\NiuNiuBridge.ex5` 即成功。

> **这一步实际做了两件事**：把 EA 文件拷进 MT5；把一把**本机随机生成的密钥**写进 MT5 沙箱。
> 密钥只在「安装 EA」这一刻写入，EA 只在启动那一刻读取——所以**顺序不能反**：先点安装，再挂 EA。

### 2.4 第四步：把 EA 挂到图表（最关键，必须手动）

牛牛 AI 只把 EA 文件放进了 MT5，**它不会替你挂**。必须手动挂一次：

1. 在 MT5 里按 `Ctrl+N` 打开「导航器」。
2. 展开「**EA 交易**」，找到 **NiuNiuBridge**。
3. **拖到任意一个图表上**（比如 EURUSD）。松手后弹出「EA 属性」窗口。
4. 「**常用**」标签页：勾上「**允许算法交易**」。
5. 「**输入参数**」标签页：
   - `InpAutoTrade` → 改成 **`true`** ← **不改这个，下单一定失败**
   - `InpDemoOnly` → 保持 `true`（测试阶段）
6. 点「确定」。
7. 确认三件事全部满足：

| 检查项 | 正常状态 |
|---|---|
| MT5 工具栏「自动交易 / Algo Trading」按钮 | **绿色**（不绿就点一下） |
| 图表右上角图标 | **笑脸** 😊（✕ = 没允许算法交易；😴 = 没挂好） |
| 底部「工具箱 → EA 交易」日志 | 有 `[NN] ═══ 牛牛 AI 桥接 EA 已启动 ═══` |

> **如果你是先挂 EA、后点的「安装桥接 EA」**：密钥是在 EA 启动时才读取的，请把 EA 从图表移除再重新拖一次（或图表右键 →「EA 交易」→「属性」→ 确定），让它重新初始化。

### 2.5 装完自检

回到牛牛 AI「**概览**」页，对照下表：

| 你看到的 | 含义 | 怎么办 |
|---|---|---|
| 余额 / 净值 / 可用保证金 有数字 | ✅ 已连上 | 继续 |
| 品种、买价、卖价 有数字 | ✅ 行情通了 | 继续 |
| 绿色小字「签名校验已启用」 | ✅ 安全链路通了 | 继续 |
| 红色「未启用签名 · 交易命令将被拒绝」 | ❌ EA 没拿到密钥 | 回 2.3 重装点安装，再回 2.4 重启 EA |
| 一直是「未连接 / EA 未运行」 | ❌ EA 没在跑 | 回 2.4 检查笑脸和绿色按钮 |

## 3. 六个页面逐一讲解

左侧导航共 6 页，加上两条全局信息（授权状态条、右上角的一键停用按钮）。

### 3.1 概览

**干什么：** 账户与持仓总览，启动后的默认页。

**你会看到：**
- 顶部三步引导条：① 选择终端 → ② 安装桥接 EA → ③ 绑定与下单（完成到哪步亮到哪步）。
- 「账户与行情」卡片：余额、净值、可用保证金、品种、买价、卖价、签名状态徽标。
- 「持仓 Positions」表：MT5 当前全部持仓（单号 / 品种 / 方向 / 手数 / 开仓价 / 止损 / 盈亏）。

**关键操作：** 主要是看。装完自检（2.5）就在这一页做。

**常见问题：** 数字全是「—」= 没连上 EA，回 2.4 检查。

### 3.2 终端与 EA

**干什么：** 管理「牛牛 AI ↔ MT5」这条连接。

| 按钮 | 作用 | 什么时候用 |
|---|---|---|
| 重新扫描 | 重新找本机的 MT5 终端 | 刚打开 MT5 但列表是空的 |
| 安装桥接 EA | 拷 EA 文件 + 写入密钥 | 首次安装（2.3）；密钥丢失重装 |
| 重新绑定（换账户） | 换 MT5 登录账户后重新绑定 | **每次换账户后必点** |

**常见问题：**
- 装了多个 MT5？列表会各列一条，**选你挂了 EA 的那个**，各终端相互独立。
- 换账户后旧命令全部失效，这是正常现象（绑定代次变了），重新下单即可。

### 3.3 交易

**干什么：** 人工下单 + 平仓 + 看回执。左边是「交易票据」，右边是「事件与回执」日志。详见第 6 章。

**常见问题：** 「确认下单」按钮是灰的 = 没连上 / 没授权 / 已停用，按 2.5 逐项排查。

### 3.4 策略广场

**干什么（现状）：** 策略资产库已上线。顶部是四格统计（候选 15 / 暂缓 4 / 排除 4 / 已实现模板 3），下方是候选资产卡片列表，可按「候选 / 暂缓 / 排除」筛选。

**关键理解：候选 ≠ 已通过。** 所有候选资产 `validation_stage=research`、`execution_status=disabled`、绩效全空——没跑过回测的策略不上（模拟）盘。上架要走四道门槛（机制合规 → 参数可复现 → 回测可查 → 模拟验证）。

**你现在能做的：** 三个模板（NN-T01/T02/T03）已经实现，以「策略 EA」的形式手动跑，见第 4、5 章。

### 3.5 AI 副驾驶

**干什么（现状）：** AI 一键下单已上线，但处于**链路演示模式**（AI 模型尚未接入）。页面有「生成示例建议」按钮，点它会产出一条示范建议卡，走通「建议卡 → 一键下单 → 二次确认 → 回执」全流程。

**关键理解（安全底线）：** AI 只给方向、点位、止损止盈、风险%；**手数由系统按「风险% × 余额 ÷ 止损距离」确定性计算，AI 不碰数字**；止损必带，无止损不出按钮；点「一键下单」后仍需二次确认才会真正下单。

**注意：** 如果部署方配置了 AI 服务地址，顶部会出现「AI 积分」状态条（粘贴 `nk1-…` 令牌连接、充值、断开）。没配置就整条不显示，属正常。

### 3.6 设置

**干什么：** 外观设置，选择后立即生效并记住。

| 设置项 | 选项 |
|---|---|
| 主题 | 浅色 / 深色 / 跟随系统 |
| 配色 | 品牌橙（默认）/ 深海蓝 / 翡翠绿 / 紫罗兰 |

**常见问题：** 设置只改外观，不影响交易功能。

## 4. 策略广场怎么用（含三个模板说明）

### 4.1 三个模板是什么

| 模板 | 思路 | 建议品种 | 建议周期 |
|---|---|---|---|
| NN-T01 趋势回撤 | 顺着趋势，等价格回踩再进场 | XAUUSD / EURUSD / NAS100 | H1 |
| NN-T02 区间突破 | 价格突破盘整区间时追进去 | XAUUSD / USOIL / NAS100 | H1 / H4 |
| NN-T03 有界均值回归 | 价格偏离均线太远时赌它回来 | EURUSD / GBPUSD / AUDUSD | H1 |

三个模板共用同一个策略 EA（`NiuNiuStrategy`），靠参数切换，不用改代码。

### 4.2 「订阅」现状

在线订阅入口**规划中，尚未开放**（见 3.4）。现在要用策略，走第 5 章手动挂 EA，效果等同。

### 4.3 风险预算（同时跑多个模板时必读）

- **Magic 号只做逻辑隔离，不做风险隔离**：余额、净值、保证金、回撤全部是共享的。
- 同时跑 2–3 个模板：每个 `InpRiskPct` 降到 **0.5–0.7**；跑 4–6 个：降到 **0.3–0.5**；**所有策略合计风险控制在 2.5% 以内**。
- **净额账户（Netting）下同品种只有一个净头寸**，想同品种跑多个策略必须用对冲账户（Hedging）。
- **没跑过回测的策略不要上（模拟）盘。** 模板自带的业绩字段在跑过回测之前是空的，这是正常状态，不代表「零收益」。

## 5. 策略 EA 怎么跑

### 5.1 和桥接 EA 的区别（先分清）

| | 桥接 EA（NiuNiuBridge） | 策略 EA（NiuNiuStrategy） |
|---|---|---|
| 角色 | **指令执行器**：接收牛牛 AI 的命令去下单 | **自主策略**：自己在 MT5 里算信号、自己下单 |
| 装法 | 牛牛 AI「终端与 EA」页一键安装 | 手动编译 + 手动挂图 |
| 信号来源 | 你点按钮 | EA 自己算 |
| 挂几个 | 一个图表挂一个就够 | **一个图表 = 一个策略实例**，跑第二个模板就再开一个图表 |

两者可以共存于同一账户，前提是 Magic 号不同。

### 5.2 编译（只做一次）

1. 打开 MT5 自带的 MetaEditor（MT5 里按 `F4`）。
2. 打开 `NiuNiuStrategy.mq5`，按 `F7` 编译，得到 `NiuNiuStrategy.ex5`。

### 5.3 挂图与参数

1. 按第 4.1 表选好品种和周期，开一个图表。
2. 导航器里把 **NiuNiuStrategy** 拖到图表上。
3. 「常用」页勾「允许算法交易」。
4. 「输入参数」页按下表设置：

| 参数 | 含义 | 建议值 |
|---|---|---|
| `InpStrategy` | 选哪个模板（0=趋势回撤 / 1=区间突破 / 2=均值回归） | 按模板选 |
| `InpMagic` | 魔术号，**每个图表必须不同** | 810001 / 810002 / 810003 |
| `InpRiskPct` | 单笔风险（占余额 %） | 0.5 起，多实例见 4.3 |
| `InpMaxPositions` | 本 EA 同时最多持仓笔数 | 1 |
| `InpMaxDailyLossPct` | 当日最大回撤（%），触及当日停手 | 2.0 |
| `InpMaxSpreadPoints` | 点差上限（point），超过不开仓 | 30 |
| `InpCloseOnStop` | 移除 EA 时是否平掉它的仓 | **默认 false（不平）**，要平需显式改 true |

5. 确认工具栏「自动交易」为绿、图表右上角是笑脸。

> ⚠️ **移除策略 EA 不等于平仓**（`InpCloseOnStop` 默认 `false`）。想一键清掉该策略的持仓，先把参数改成 `true` 再移除。
> 止损止盈默认按 ATR 自动计算（`InpAtrSlMult` / `InpAtrTpMult`），不懂就保持默认。

## 6. 下单与平仓（「交易」页）

### 6.1 下单步骤

在左侧「**人工下单 · 交易票据**」卡片填：

| 字段 | 说明 | 建议测试值 |
|---|---|---|
| 方向 Side | 买入 BUY / 卖出 SELL | 买入 BUY |
| 手数 Lots | 交易手数 | **0.01**（最小手，测试用） |
| 止损（点）`sl_points` | 填 0 = 不设 | 0 或 250 |
| 止盈（点）`tp_points` | 填 0 = 不设 | 0 或 500 |
| 允许滑点（点） | 允许的价格偏离 | 30 |

然后：

1. 看下面的「**下单前确认**」小票：账户、服务器、品种、方向手数、止损止盈逐项核对。**不对就别点。**
2. 确认无误，点「**确认下单（模拟盘）**」。

> **「点」是什么？** point = 该品种的最小报价单位，**不是 pip**。比如黄金 1 point ≈ 0.01 美元。手数和止损距离 EA 还会按券商规格（VOLUME_STEP / STOPS_LEVEL）再校验一遍——桌面端校验通过不代替 EA 校验。

### 6.2 回执状态全解（建议读一遍）

下单后看右侧「事件与回执」：

| 状态 | 什么意思 | 你要做什么 |
|---|---|---|
| `已发出` | 命令发出去了，EA 还没回话 | 等 |
| `已受理` | EA 校验通过，正在提交券商 | 等 |
| `已成交` | 券商确认成交 | 无 |
| `已拒绝` | 明确失败 | 读后面的原因文字（如「手数越界」「止损距离小于 STOPS_LEVEL」「EA 自动交易开关关闭」），不用猜 |
| `已过期` | 命令超过有效期才开始处理 | 可以重发，不会重复成交 |
| **`待核对`** | **结果不明**：请求可能已发出，但不知道成没成 | **去 MT5 看真实持仓，禁止重复下单** |

> ⚠️ **「待核对」是刻意设计，不是 bug。** 系统永远不替你自动重发一条结果不明的命令——那才会真的重复成交。宁可让你看到「待核对」，也不给你一个假的「已成交」。

### 6.3 平仓

1. 「**概览**」页的「持仓 Positions」表里，找到要平的那一行。
2. 点最右边的「**平仓**」，弹确认框，确认。
3. 平仓同样走一遍回执流程；成功后持仓从表格和 MT5 里同时消失。

## 7. 一键停用与换账户

### 7.1 一键停用（急停）

- 点顶部右上角「**运行中 · 点击停用**」→ 变成「⛔ 已停用」。再点一次恢复。
- 这是**主进程里的真闸门**，不是界面摆设：停用后不再接受任何新的交易指令。
- **但已发出的命令仍会走完**——这是对的，半路掐断才可能造成状态不一致。

| 想做什么 | 怎么做 |
|---|---|
| 暂停牛牛 AI 的指令入口 | 点「一键停用」 |
| 彻底停止一切自动交易 | MT5 里点「自动交易」按钮变红，或把 EA 从图表移除 |
| 完全清理 | 卸载牛牛 AI 后，还要在 MT5 里删除 NiuNiuBridge（图表移除 + 导航器删文件），并删掉 `MQL5\Files\niuniu\` 文件夹 |

### 7.2 换账户

1. 在 MT5 里登录新账户。
2. 回牛牛 AI「**终端与 EA**」页，点「**重新绑定（换账户）**」。
3. 旧命令会全部失效（绑定代次变了），正常现象，重新下单即可。
4. 不换绑定就下单，会被拒：回执写「账户不匹配」。

## 8. 故障排查表

| 现象 | 原因 | 解决 |
|---|---|---|
| 终端列表空 / 显示「EA 未运行」 | EA 没挂图，或自动交易没开 | 回 2.4，检查笑脸和绿色按钮 |
| 下单立刻被拒：「EA 自动交易开关关闭」 | `InpAutoTrade` 还是 `false` | 2.4 第 5 步改成 `true` |
| 下单被拒：「仅允许模拟盘」 | 登录的是实盘账户 | 换模拟账户 |
| 红色「未启用签名 · 交易命令将被拒绝」 | EA 没拿到密钥 | 重点「安装桥接 EA」→ 重启 EA |
| 命令一直停在「已发出」 | EA 没在跑，或选错终端 | 确认选的是挂了 EA 的那个终端 |
| 全部被拒：「账户不匹配」 | 换账户后没重新绑定 | 点「重新绑定（换账户）」 |
| 换账户后旧命令失效 | 正常现象（代次变了） | 重新下单即可 |
| 「止损距离小于 STOPS_LEVEL」 | 止损设太近 | 止损点数调大 |
