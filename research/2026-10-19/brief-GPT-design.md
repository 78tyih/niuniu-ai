# Brief · GPT 设计蓝图（策略广场生态库 + 交易 Prompt 库 + 教程结构）

你是资深产品架构师。请为「牛牛 AI」设计三样东西的**蓝图**（不是最终文案，是结构与规则）。牛牛 AI 是一个装在用户本机的 MT5 交易副驾驶（Windows Electron 桌面端）。

## 一、现状（事实，别改）

客户端已经上线 6 个页面（左侧导航）：
1. 概览（账户/持仓/资金曲线总览）
2. 终端与 EA（MT5 终端发现 / 安装桥接 EA / 授权状态 / 重新绑定）
3. 交易（人工下单 / 平仓 / 回执跟踪 / 一键停用）
4. 策略广场（策略模板列表 / 订阅）
5. AI 副驾驶（对话 / 总结，尚未接模型）
6. 设置（主题 / 配色 / 教程 / 客服）

交易链已打通并真机校验：桌面端 → 主进程 → 桥进程 → MT5 EA → 券商。EA 只实现 3 种命令（市价开仓 / 按单号平仓 / 刷新状态）。

策略模板：现有 3 个首批（趋势回撤 / 区间突破 / 有界均值回归，共用 1 个参数化 EA），另有 23 个设计资产（research/2026-10-18/templates-v1.clean.json，风格分布 trend 6 / mean_reversion 3 / breakout 3 / grid 2 / dca_martingale 2 / scalping 2 / swing 1 / arbitrage 2 / other 2），但**都未回测，绩效字段必须留空**。

## 二、硬约束（设计必须遵守）

- **禁止编造绩效数字**：未回测的模板绩效写 null，回测标「回测」，实盘标「实盘」，三者不混榜。
- **AI 的边界**（来自 mojo.trade 调研事实）：模型只做「解读 / 总结 / 建议」，**不下单量换算、不做止损落地**——可用余额、下单量、止损由确定性程序算，模型不参与。
- **MT5 事实**：一图表挂一个 EA；Magic 只做逻辑隔离不做风险隔离（余额/净值/保证金/回撤全共享）；净额账户（Netting）同品种只有一个净头寸、Magic 在该品种失效。
- **不做**：马丁/网格/逆势加仓/无止损模板/保本承诺/代客理财/资金托管。
- **中文优先**。

## 三、你要设计的三个东西

### 1. 策略广场「生态库」的完整信息架构与运营机制
- 如何从「3 个模板」演进成「可持续运营的生态库」：分类体系（决策方式 × 交易风格 × 风险档 × 方向）、模板卡字段分级、详情页段落、筛选/排序、上架门槛（回测→模拟盘→实盘的分级）、策略方接入与分润机制。
- 关键问题：23 个设计资产里哪些该进 v1 生态库、哪些该砍（grid / dca_martingale / scalping / arbitrage 各自的风险与是否违背「不做清单」）？
- 给出「生态库目录结构」（JSON schema 或目录约定），能直接落地成代码/数据。

### 2. 交易 Prompt 模板库（AI 副驾驶的提示词体系）
- AI 副驾驶需要哪些 prompt 模板：系统身份设定、能力边界声明、行情解读、持仓分析、交易决策辅助、风控提醒、以及「什么时候必须拒绝回答」。
- 每个 prompt 给出：用途 / 触发场景 / 模板正文 / 必须遵守的红线（如：不给具体下单建议、不预测价格、不承诺收益、提醒风险）。
- 特别设计：如何让 AI「诚实」（数据不足时说不知道，不编造行情/收益）。

### 3. 网站教程重构大纲
- 客户端从「单页交易链」升级为「6 页」，教程必须跟着重构。
- 给出新教程的章节大纲：覆盖 6 页 + 安装 EA + 策略 EA 使用 + 策略广场订阅 + 回执状态理解 + 风险提示 + 故障排查。
- 每章标注「面向小白的一句话目标」+「必讲的关键概念」。

## 四、输出

写成一个文件 `answer-design-blueprint.md`，结构清晰、可直接被下游（K3 施工）引用。设计里凡是「我建议」的地方，标清楚理由；凡是「事实」的地方，别编。

设计要克制——牛牛 AI 是给小白用的交易工具，不是给量化机构。过度设计 = 减分。
