## 任务A：看板 DIY 机制

> 以下基于同类交易终端与可定制工作区的设计模式推演，**不是对 mojo.trade 现有界面的实测复刻**。组件清单代表可选能力，不建议全部放进牛牛AI首版。

### 1. 组件类型清单

| 分类 | 组件 | 显示内容 |
|---|---|---|
| 账户 | 账户资产卡 | 余额、净值、浮动盈亏及账户币种。 |
| 账户 | 可用保证金卡 | 已用保证金、可用保证金及保证金水平。 |
| 账户 | 当日表现卡 | 当日已实现盈亏、浮动盈亏和交易次数，明确统计口径。 |
| 账户 | 多账户概览 | 各 MT5 账户的净值、盈亏和连接状态。 |
| 账户 | 资金流水 | 入金、出金、手续费、隔夜费及其他余额变动。 |
| 交易 | 持仓列表 | 当前品种、方向、手数、开仓价、止损止盈和浮动盈亏。 |
| 交易 | 挂单列表 | 待成交订单的价格、数量、类型及有效期。 |
| 交易 | 成交记录 | 已执行交易的成交时间、价格、数量和费用。 |
| 交易 | 快捷下单 | 指定品种的报价与下单入口，提交交易需独立确认。 |
| 行情 | 自选列表 | 自选品种的最新报价、涨跌幅与迷你走势。 |
| 行情 | 单品种报价卡 | 买价、卖价、点差及市场开闭状态。 |
| 行情 | K线图 | 指定品种、周期的价格走势、指标及交易标记。 |
| 行情 | 深度／订单簿 | 可用数据源提供的买卖档位和数量；不将其包装成外汇全市场订单簿。 |
| 行情 | 逐笔成交流 | 数据源支持的逐笔成交价格、数量及方向。 |
| 行情 | 市场热力图 | 按板块或资产类别展示涨跌与相对强弱。 |
| 行情 | 多品种对比 | 多个品种在同一区间内的标准化走势。 |
| 行情 | 市场时钟 | 主要交易时段、开收盘时间与假期状态。 |
| 分析 | 净值／资金曲线 | 账户净值或余额随时间变化，注明是否剔除出入金影响。 |
| 分析 | 收益日历 | 按日或月展示已实现盈亏分布。 |
| 分析 | 绩效统计 | 胜率、盈亏比、交易次数等指标及样本区间。 |
| 分析 | 回撤卡 | 当前回撤、历史最大回撤及对应时间。 |
| 风险 | 敞口分布 | 按品种、方向或币种汇总持仓风险暴露。 |
| 风险 | 风险提醒 | 保证金不足、集中持仓、止损缺失或风险限额触发。 |
| 信息 | 财经快讯 | 按品种、主题或来源筛选的新闻流。 |
| 信息 | 经济日历 | 经济事件、发布时间、影响级别及公布值。 |
| 信息 | 价格／指标提醒 | 用户设定的条件、触发记录及当前状态。 |
| 策略 | 策略状态卡 | 策略运行、暂停或异常状态，以及最近执行时间。 |
| 策略 | 策略条件卡 | 可执行规则、当前条件是否满足及下一次检查时间。 |
| 策略 | 信号队列 | 新信号、待确认信号及过期状态。 |
| 策略 | 执行日志 | 条件触发、风控拦截、下单结果和失败原因。 |
| 策略 | 回测摘要 | 指定参数与历史区间下的收益、回撤和交易次数。 |
| AI | AI 助手入口 | 自然语言提问、策略草拟与当前账户上下文入口。 |
| AI | AI 分析摘要 | 分析结论、依据与生成时间，明确区分分析和执行指令。 |
| 工作区 | 待办／交易计划 | 盘前检查、观察条件和待完成事项。 |
| 工作区 | 交易笔记 | 交易理由、复盘摘要和图表备注。 |
| 系统 | 连接健康卡 | MT5、行情源及策略执行服务的连接和同步状态。 |

**牛牛AI首版优先：**账户资产、持仓、自选、K线、策略状态、风险提醒、AI入口。其余逐步扩充，避免先做庞大的“组件市场”。

### 2. DIY 交互机制

**推荐模型：预设模板起步 + 网格布局 + 独立编辑模式。**

- **新增**
  - 顶栏「编辑」进入编辑模式，再点「＋添加组件」。
  - iPhone 用底部组件抽屉；iPad／桌面可用右侧侧栏。
  - 抽屉按「账户、行情、策略、风险、工具」分类，支持搜索和预览。
  - 点选组件 → 完成必要配置 → 添加到当前画布末尾并定位。
  - 同类组件允许重复，例如分别查看黄金和欧元图表；用标题区分。

- **拖拽排序／换位**
  - 编辑模式下显示拖拽手柄，长按后组件抬起并轻微触觉反馈。
  - 拖动时出现占位框，其他组件实时让位；靠近边缘自动滚动。
  - 默认采用**插入排序**；多列布局可按目标网格重新排布，避免不可预测的任意交换。
  - 浏览模式保留图表缩放、列表滚动等手势，避免误拖整个组件。
  - 同时提供「上移／下移」菜单，支持无障碍操作。

- **调整尺寸**
  - 组件菜单提供「小／中／大」和即时预览，只展示该组件支持的尺寸。
  - iPhone 以全宽卡片为主，尺寸主要改变高度与信息密度；简短指标可占半宽。
  - iPad 可映射为不同网格跨度；图表与持仓列表设最小尺寸。
  - 尺寸变化应调整展示内容，而不是单纯缩小字体。

- **配置单个组件**
  - 「••• → 配置」打开底部弹层。
  - 通用项：名称、账户、品种／自选池、时间范围。
  - 专属项：图表周期与指标、持仓排序、新闻主题、策略筛选等。
  - 可选择「跟随看板账户／品种」或「固定账户／品种」，并显示绑定关系。
  - 配置展示组件与修改策略执行参数应使用不同入口，避免误操作。

- **删除**
  - 编辑模式下用「移除组件」，移除后提供短暂「撤销」。
  - 明确：**移除策略卡片不等于停止策略，也不删除交易记录。**
  - 停止策略等执行操作，应放在策略详情中独立处理。

- **布局**
  - 推荐**网格吸附 + 自动补位**，不采用任意坐标自由画布。
  - iPhone 采用单列为主、少量双列指标；iPad 使用多列网格。
  - 保存组件顺序、尺寸和配置，根据屏幕宽度重新排布。
  - 初始提供「账户监控」「行情观察」「策略运行」模板，避免空白画布。

- **保存**
  - 编辑期间暂存布局；点「完成」保存，点「取消」恢复进入编辑前的状态。
  - 行情继续更新，但编辑布局不触发交易，也不改变策略运行状态。

### 3. 信息架构层级

```text
看板
├─ 顶栏
│  ├─ 看板名称 / 看板切换
│  ├─ 当前账户选择
│  └─ 浏览态：编辑
│     编辑态：取消、添加组件、完成
│
├─ 画布区
│  ├─ 首次使用：模板选择 / 添加首个组件
│  ├─ 组件网格
│  │  ├─ 标题、账户 / 品种、状态
│  │  ├─ 核心内容
│  │  └─ 更多菜单 / 编辑手柄
│  └─ 加载、无数据、连接中断、数据过期提示
│
├─ 组件抽屉
│  ├─ 搜索与分类
│  ├─ 组件预览与一句话说明
│  ├─ 支持尺寸 / 数据依赖
│  └─ 添加按钮
│
└─ 单组件编辑弹层
   ├─ 名称与尺寸
   ├─ 数据来源：账户、品种、策略
   ├─ 时间范围、过滤与排序
   ├─ 跟随看板 / 固定配置
   └─ 取消、保存
```

**视觉建议：**浅色底、轻磨砂卡片、稳定留白；`#FF6A1A` 用于主操作与选中态。涨跌、告警、授权状态使用独立语义色，并配文字或图标。图表和密集数据区域保证底色稳定，避免透明叠层影响读数。

## 任务B：极简个人交易账户页

### 1. 分组排序

建议采用 **顶部账户卡 + 三组列表**，容纳全部八项：

| 顺序 | 分组 | 包含项目 | 排序理由 |
|---|---|---|---|
| 1 | 账户与授权 | ① MT5 授权状态 | 这是产品能否工作的前提，异常时需要最先发现。 |
| 2 | AI 用量与充值 | ② AI 网关、③ 充值入口 | 额度与补充额度属于同一任务，合并展示减少跳转。 |
| 3 | 偏好与设置 | ⑤ 主题、⑥ 设置 | 常规配置集中放置，视觉权重低于账户状态。 |
| 4 | 帮助与分享 | ⑦ 使用教程、⑧ 客服联系方式、④ 邀请链接 | 先解决使用问题，再提供分享入口，避免营销抢占首页。 |

建议页面顺序：

```text
我的
[ MT5 账户 · 掩码账号              已授权 › ]

[ AI 用量 · 剩余额度               充值   ]

[ 主题                            跟随系统 › ]
[ 设置                                    › ]

[ 使用教程                                › ]
[ 联系客服                                › ]
[ 邀请好友                           复制链接 ]
```

- 不额外堆一张巨大的头像、昵称、会员等级卡；必要身份信息可融入顶部。
- 授权异常时，在账户卡内显示原因和「重新授权」，不新增整屏警告区。
- 退出登录、解绑账户、注销账户放进对应详情页底部，不占主页面。

### 2. 逐项控件形态

| 项目 | iOS 风格控件建议 | 交互与文案要点 |
|---|---|---|
| ① 授权状态 | 顶部磨砂卡：MT5 图标、掩码账号、文字状态徽章、右侧 chevron | 整卡进入授权详情；区分「未绑定／已授权／授权失效」。连接状态另行标注，避免把断线误写成授权失效。 |
| ② AI 网关 | 紧凑用量卡：主数值 + 单位 + 辅助说明 | 用户侧建议命名「AI 用量」；明确积分、次数或额度单位。只有固定总额度时才用进度条。 |
| ③ 充值入口 | 内嵌在用量卡右侧的小型橙色「充值」按钮 | 不单独占一张卡；点击后选择充值方案，未选方案前不显示容易误解的金额按钮。 |
| ④ 邀请链接 | 列表行 + 右侧「复制链接」文字按钮 | 不直接铺出长 URL；复制后显示「已复制」，需要更多分享方式时再进入系统分享面板。 |
| ⑤ 主题 | 列表行显示当前值；点击打开三选一选择器 | 「跟随系统／浅色／深色」，默认跟随系统；不用只能表达两种状态的开关。 |
| ⑥ 设置 | 标准列表行：图标、标题、chevron | 通知、安全、隐私等放二级页，不在首页展开多排开关。 |
| ⑦ 使用教程 | 标准列表行 + chevron | 进入短教程目录，优先呈现绑定 MT5、使用 AI、查看策略状态等基础任务。 |
| ⑧ 客服联系方式 | 「联系客服」列表行 + chevron | 点击查看支持渠道和服务时间，支持复制联系方式；仅一个渠道时可直接进入。 |

共同细节：

- 行高约 **52–56 pt**，交互热区至少 **44 × 44 pt**。
- 整行导航用 chevron；复制、充值等即时动作使用按钮，不叠加含糊的点击行为。
- 橙色集中用于主操作，不把每个图标都染成橙色。
- 状态不能只靠颜色表达；磨砂背景下仍需保证文字对比度。

### 3. 极简红线

**极简的目标：用户一眼看清账户能否使用、AI额度是否够用、遇到问题去哪里。**

不应出现：

- **交易数据堆积**：K线、持仓、收益排行、净值曲线应回到交易看板。
- **营销抢位**：轮播广告、限时倒计时、会员促销、邀请奖励大横幅。
- **重复入口**：余额卡、积分卡、充值卡分别占据三块空间。
- **无意义身份装饰**：巨大头像区、等级勋章、成就墙和签到任务。
- **技术细节外露**：网关 URL、Token、路由模型、服务器日志放高级设置或诊断页。
- **长内容常驻**：完整邀请链接、教程正文、多渠道客服电话同时铺开。
- **破坏性操作前置**：解绑、清空数据、注销与日常入口并列。
- **无关授权索取**：进入账户页就要求通知、通讯录等权限。
- **过度玻璃效果**：多层透明卡片、强模糊与装饰性渐变影响状态辨识。

应保留的必要信息：

- 掩码账户身份与明确的授权状态。
- AI额度的单位、适用周期或过期规则。
- 异常时具体可执行的恢复入口。
- 清晰的客服与教程入口。

**推荐首屏：一张账户卡、一张用量卡、两组轻量列表。** 八项功能齐全，首屏仍以状态和操作为主。
