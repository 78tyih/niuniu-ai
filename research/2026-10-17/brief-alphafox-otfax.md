# 调研任务：AlphaFox 策略广场字段 + OTFAX 卡片前端

你在帮一个 MT5 交易 AI 助手产品「牛牛AI（niuniuai.app）」做 iOS 应用端。品牌主色橙色 #FF6A1A。产品有一个「策略广场」——策略方把自己的交易策略挂牌，用户浏览、看数据、一键跟单。请纯咨询作答。

## 任务 A：策略广场的卡片字段设计（参考 AlphaFox 这类策略跟单平台）

策略广场里，每条策略应该做成一张卡片，卡片上要展示这些核心指标：**年化收益、资金曲线、夏普比率（Sharpe）、最大回撤、交易笔数**。

请回答：
1. 一张「策略卡片」的**字段排版结构**怎么排最合理？哪些是主视觉（最大字号的数字），哪些是次要指标（小字 + 图标），哪些是辅助信息（策略名、策略方、运行天数、实盘跟随人数）？给出字段的视觉层级（一级/二级/三级）。
2. 资金曲线在一张小卡片里怎么展示？（迷你面积图？折线？要不要基准对比虚线？）涨跌用什么颜色（注意：中国市场惯例是涨红跌绿）。
3. 卡片上还应该有哪些**操作**？（跟单按钮、查看详情、收藏/对比）放在什么位置？
4. 策略广场的**列表页**和**详情页**如何分工？列表页卡片放哪些字段，点进去详情页再展开哪些字段？（例如：列表放年化/回撤/曲线/跟单按钮，详情放完整资金曲线、月度收益热力格、策略方简介、风险提示）
5. 「跟单」这个动作的**交互链路**该怎么设计？（点跟单 → 确认弹层 → 选金额/风险参数 → 提交 → 状态变成「已跟单」）请描述每一步。

## 任务 B：OTFAX 前端的卡片化交易设计

OTFAX（你可能更熟悉 OTFX，一家外汇/差价合约交易平台）的前端以「卡片化」呈现交易/资产信息著称。请基于你对卡片化交易终端的理解回答：

1. 交易类产品用「卡片」承载信息，相比表格，**视觉上的关键手法**是什么？（圆角、阴影、留白、图标化、数字大字号、颜色语义化……）请具体到可执行的 CSS/视觉规范。
2. 卡片内的**数字排版**怎么做才有「专业交易终端」的质感？（等宽数字字体、对齐方式、正负号颜色、千分位、小数点位数）
3. 一套「卡片化交易界面」的**配色纪律**是什么？（主色 + 中性灰阶 + 语义色涨跌，各自占比、用在什么元素上）
4. 卡片之间如何**成组/分区块**，避免「一屏全是卡」的拥挤感？（间距、分组标题、卡片尺寸节奏）

## 输出格式

Markdown 分两部分（任务A、任务B）。任务A 输出「卡片字段层级 + 曲线展示 + 操作 + 列表/详情分工 + 跟单交互链路」五小节；任务B 输出「卡片视觉手法 + 数字排版 + 配色纪律 + 分组节奏」四小节。多用列表。可以给 CSS 属性级建议（如 border-radius: 20px、font-variant-numeric: tabular-nums），但不用给完整 HTML。
