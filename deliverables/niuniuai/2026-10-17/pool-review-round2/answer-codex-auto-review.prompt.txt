# BRIEF（更正版）：上游号池合作 —— 事实更正 + 合规红线

## 一、更正声明

上一份 brief 第 3 节我写过「New API 管理接口全部是 Session 鉴权，没有官方开放的管理 API Token」。**这条是错的。** 现更正为实际查证结果：

New API 官方文档（docs.newapi.pro/en/docs/api/management/auth）明确：
- 支持两种鉴权方式，**任选其一**：Session（`POST /api/user/login`）**或 Access Token（官方标注 Recommended）**
- Access Token 生成位置：个人设置 → 安全设置 → **系统访问令牌**
- 请求头：`Authorization: Bearer {token}`，部分接口另需 `New-Api-User: {user_id}`
- 权限分级：Public < User < Admin < Root

用户与令牌管理接口（据代码结构分析，另有第三方改造文章佐证）：
- `POST /api/user/` — Admin 创建用户，可指定 quota
- `PUT /api/user/` — **Admin 可直接修改任意用户的 quota**，系统会留下日志「管理员将用户额度从 X 修改为 Y」
- `POST /api/token/` — 创建令牌，响应直接返回完整 key

结论：**「自动开户 + 自动调整额度」不需要 fork 源码，也不需要模拟登录或保存密码。**
