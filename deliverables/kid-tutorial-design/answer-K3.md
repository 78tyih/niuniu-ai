## 核心结论（我采纳的部分）

1. **统一比喻 = 「外卖跑腿」**，全程不换比喻：
   - 你 = 点菜的小朋友（你决定：买什么、买多少）
   - 牛牛 = 跑腿小哥（只跑腿，不决定）
   - EA = 店里收银员（在 MT5 里真执行）
   - 下单 = 点单；回执 = 小票；止损 = 「超过 50 块就别买」；策略 = 食谱 + 试吃厨房（回测 = 先试做 100 遍再上桌）
   - 拟人红线：牛牛绝不被画成「自己决定买不买」；不说「帮你赚钱」只说「帮你跑腿」。

2. **信息结构：10 章 → 6 关 + 备用小抄（折叠）**
   - 封面内页（牛牛是谁，一张分工图）
   - 第1关 把牛牛请回家（装MT5+装牛牛AI）
   - 第2关 给小哥办进店证（装桥接EA + 手动拖到图表）——新手失败率最高，给足篇幅
   - 第3关 认识牛牛的家（6 页面 = 6 个房间地图）
   - 第4关 挑一份食谱（策略广场：漏斗「试吃筛选」+ 时间轴「编译→挂图→填参数」）
   - 第5关 第一次点单（三步流程 + 对错对照表）——全教程最重要的一张图
   - 第6关 红色大按钮（一键停用 + 换账户）
   - 备用小抄（折叠）：急诊室（故障排查）、大人专区（风险提示，深色严肃风）、寄信给牛牛（反馈）

3. **可视化逐关指定**（分工图 / 两步流程图 / 连环画4格 / 户型地图 / 漏斗+时间轴 / 三步流程+对错对照 / 红按钮特写）。

4. **视觉规范（照抄）**
   - 5 色系统：暖黄 #FFC63A / 功能绿 #3BB273 / 警示红 #E4572E / 奶白 #FFF9EF / 深棕 #3A2E26
   - 标题圆体 28–36pt ≤10 字；正文思源黑体 Bold 14–16pt；每页正文 ≤60 字
   - 圆角 16px（卡片）/ 999px（按钮标签）；图标 3px 粗描边扁平风；截图 8px 圆角 + 2px 深棕描边 + 投影（贴纸感）
   - 一屏一个信息点；留白 ≥35%；页脚关卡进度点 + 页码
   - 动效只用两种：元素自下淡入（stagger 80ms）+ 箭头 stroke 画线；禁止弹跳/旋转/粒子

5. **必避的坑**：过度拟人诱导、比喻混用、信息密度回潮、图表装饰化、emoji 当图标、待核对轻描淡写、风险提示做萌、截图过期。

## 施工顺序（K3 建议）
先画「第5关对错对照图」+「封面分工图」确认比喻体系，再铺开其余——比喻是地基，返工成本最高。
