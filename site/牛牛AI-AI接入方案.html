AI 到底接哪里？
以及积分体系怎么搭

2026-10-16 · 面向牛牛 AI 桌面端 · 价格均为官方公开价（当日查询，见文末来源）
先看结论

自建中转网关 + 自研计费层，上游主接国产（DeepSeek V4-Flash 打底，豆包 / 千问做备份），GPT 只做「高端档」可选项。

理由三条：① 客户端绝对不能拿到模型 Key —— Electron 包一扒就光，必须服务端代理，这一步顺带就把积分、限流、审计都做进去了； ② 国产三家都兼容 OpenAI 协议，切换成本近乎为零，不会被单一厂商涨价绑架（DeepSeek 8 月刚涨过一轮，输出价 +350%）； ③ 你已经有 Supabase 账号体系 + ZPay/Stripe 支付 + Zeabur 部署 —— 积分直接长在这套上面，不用从零造。

1一句话回答「接哪里」

按你现在的情况（客户在国内、软件是交易工具、要卖积分），答案不是"接某个模型"，而是"先有一层你自己的网关"。

2三条路，为什么选第三条

四种常见做法的取舍。

A · 客户端直连官方 API

✕ 不可行
  • Key 必然泄漏：我们的包是 asar:false（沙箱写文件要求），一解包就是明文 Key
  • 无法扣积分、无法限流、无法封停某个用户
  • 国内用户直连 OpenAI 还有网络与 ToS 问题

B · 买现成中转站给客户用

△ 只能当备胎
  • 省运维，接入快 —— 适合做上游备线
  • 倍率和套餐不在你手里，积分毛利被压一层
  • 它自己涨价 / 跑路，你的产品跟着死
  • 等于替别人卖流量，不做

C · 自建网关 + 自研计费（推荐）

✓ 主线
  • New API / One API 一类开源网关做上游聚合与故障切换
  • 上面再叠自己的计费层：鉴权 → 查积分 → 扣减 → 调模型 → 记用量
  • 成本、倍率、套餐、封停全在你手里
  • 上游可热切换，涨价就换

D · 自建网关并对外卖 API

✕ 现在别做
  • 看起来多一条收入线
  • 合规、滥用、内容审核都是新坑
  • 和"交易助手"品牌混在一起，风险外溢

3架构：请求怎么走

客户端永远拿不到模型 Key，也永远不直接对模型厂商发请求。

6积分体系怎么设计

目标：客户看得懂、你算得清、薅不走。

计价方式：卖积分，消耗按 token 折算

项目建议
积分单价1 积分 ≈ ¥0.1（套餐越大越便宜）
快问（默认档）1 积分 / 次（成本约 0.1 分，毛利 90%+）
深度分析5–10 积分 / 次
注册赠送50 积分（试用钩子，够用两三天）
套餐¥29 = 300 积分 · ¥98 = 1200 积分 · ¥298 = 4000 积分
前端每次回答后显示「本次消耗 1 积分 · 剩余 287」—— 把消耗透明化，比"无限使用"更让人放心，也防薅。

四条必须写进代码

  • 预扣 + 结算：请求前冻结，拿到真实用量后多退少补。中断/超时必须退回，否则客诉。
  • 每日上限：防脚本刷量，异常用量自动告警。
  • 用量流水落库：每次调用记 user / 模型 / token / 积分 / 耗时，既是账单依据也是审计。
  • 余额不足要优雅降级：提示充值，不要白屏或半截回答。

7路线图：分四步，每步有验收标志

P0 先跑通闭环，别一上来做多模型。

P0 · 约 1 周

服务端代理 + 积分扣减 + 聊天框

在 Zeabur 上起一个 Node 服务：/v1/chat，验 token → 查积分 → 调 DeepSeek-V4-Flash → 扣减 → 记流水。客户端加一个只读的问答框。

验收：客户端能问一句「我现在的持仓怎么样」，拿到回答，积分正确扣 1。
P1 · 约 2 周

工具调用（Function Calling）

暴露 get_quote / get_positions / get_account 三个工具给模型，结构化输出在客户端渲染成卡片，而不是一大段文字。

验收：AI 能读到真实持仓和报价并给出结构化结论，且全程不触发任何下单动作。
P2

双档模型 + 套餐 + 用量看板

「快 / 深」两档切换；接入豆包与千问做备份；积分套餐上现有 ZPay/Stripe；给运营一个用量与毛利看板。

验收：上游任意一家挂掉，服务自动切换且用户无感。
P3

策略 / 回测 Agent（单独计价）

token 消耗大，不要塞进普通积分。做成独立功能包或按次高价计费。

验收：单次成本可控、结果可复现、有明确免责声明。

8红线（这五条不能碰）

红线为什么
模型 Key 绝不进客户端Electron 包可解（我们是 asar:false），进了就等于公开。只放服务端环境变量。
AI 不自动下单交易工具 + 自动执行 = 合规与客诉雷区。v1 的 AI 只做"读和解释"，下单按钮始终人点。
不承诺收益"AI 帮你赚钱"是把自己送上被告席。定位为分析辅助，免责声明放在每次回答旁。
不对外卖 API那是另一门生意，合规与滥用成本极高，现在不碰。
敏感字段不落库明文账户号、持仓、余额属于高敏数据；服务端日志脱敏，留存策略写清楚。
