对接需求清单 · 供贵方技术 / 商务负责人填写

牛牛AI 接入浩驰（Fomalhaut MaaS）服务
需贵方提供的材料清单

我方以自有品牌「牛牛AI」向境内交易用户提供 AI 助手服务，拟采购贵方 MaaS 推理能力作为上游。以下为启动对接前需贵方提供与确认的事项，请逐项填写或提供。

一技术对接（请提供）

用于我方完成上游适配层开发与联调。核心是确认接口协议与计费口径。

事项需提供 / 确认
必填API 地址API Base URL（是否 OpenAI /v1/chat/completions 兼容格式）
必填鉴权方式API Key / Bearer Token 的签发方式与使用说明
必填模型清单可调用的模型名（精确到版本），及每个模型的输入 / 输出单价（人民币 / 百万 tokens）
必填缓存计价缓存创建 / 缓存读取的计价规则（如缓存读取 = 输入价 0.1x）
必填计费与结算结算方式（预充值 / 后付费 / 月度账单）、额度单位与充值方式
必填用量查询用量 / 余额查询方式（API 接口 或 后台导出），账单导出格式
必填限流与稳定性QPS / 并发上限、单次超时时间、可用性 SLA、故障通知渠道
建议测试环境测试 API Key 与小额测试额度，供我方联调验证

二商务资质（请提供，用于合规尽调）

我方面向境内付费客户，需确认贵方货源与授权链，以隔离合规风险。

事项需提供 / 确认
必填企业主体营业执照；签约主体、收款主体、开票主体是否一致
必填授权链与模型厂商（OpenAI / Anthropic 等）的采购合同或授权证明；明确允许向境内第三方分销 / 转售的条款
必填合规信息模型备案 / 登记信息（如适用）；数据处理说明（提示词数据去向、留存期、是否用于训练）
必填税务票据可开具的发票类型（增值税专用发票？）；结算周期与付款方式

三合同要点（请在协议中明确）

条款说明
转售授权允许我方以自有品牌向境内客户提供服务，模型能力嵌入我方软件
不绕客不得绕过我方、直接接触或营销我方终端客户
价格调整调价需提前通知（如 15 / 30 天），我方享有议价期
预付与退款预付额度上限；未使用额度的退款条款
终止过渡合作终止的过渡期、客户数据导出、未结账单处理
SLA 与赔偿可用性承诺（报价单载明 99.9%+）、故障响应、违约赔偿

四我方对接方式（贵方了解即可）

环节我方做法
接口接入通过 OpenAI 兼容接口调用；贵方 API Key 只存我方服务端，不进客户端
计费我方按 token 用量向客户计费，售价 = 贵方采购价 × 3
客户隔离终端客户只连我方网关，看不到贵方地址、密钥与客户名单
对账按周期（日对账 / 周结算）与贵方核对用量与账单
请贵方技术负责人按「第一部分」返回接口信息，商务负责人按「第二、三部分」返回资质与合同意见。 我方在收到接口信息后即可启动上游适配层开发与联调，商务材料用于并行推进合规尽调。
